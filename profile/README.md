# Hypertrial

**Verifying What AI Builds**

Hypertrial builds open-source tools for software verification. Mentat checks Git commits against contracts you approve, runs behavior tests, and checks formal models with Lean or Z3. It exports evidence you can reproduce. [Explore Mentat](https://github.com/hypertrial/mentat)

See how Mentat replays real open-source bugs in [Iceberg Go](https://github.com/hypertrial/mentat/blob/v0.1.2/docs/iceberg-go.md) and [Nano ID](https://github.com/hypertrial/mentat/blob/v0.1.2/docs/nanoid.md).
